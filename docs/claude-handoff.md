## 구현한 변경

1. **책장** — `components/book/BookstoreShelf.tsx`, `app/bookstore.css`
   - 읽는 중인 책을 포함해 모든 실제 책은 책등이 보이는 세로 진열입니다. 앞면 고정 진열과 눕힌 장식 책은 없앴습니다.
   - 빈 공간에는 클릭되지 않는 반투명 책등을 세웠습니다.
   - 책 클릭: 꺼내서 앞면 표시. 같은 책 다시 클릭: 제자리에 꽂기. 두 번째 클릭으로 페이지를 이동시키지 마세요.
   - 오른쪽 불투명 회색 정보 패널: 상태, 제목, 저자, 마지막 독서일, 쪽수, 읽기/상세 정보 링크. 닫기 버튼은 없습니다. Escape와 바깥 클릭도 선택을 해제합니다.
   - 카테고리별 4단 책장과 가로 넘김, 기존 조명/테마는 유지합니다. 마지막 책장에서는 다음 버튼이 비활성화됩니다.

2. **앞·뒷면 그림** — `public/covers/*.webp`, `components/book/CatalogCoverArt.tsx`, `BookCover.tsx`, `BookViewer.tsx`, `app/catalog.css`
   - 현재 16권에 독창적인 유화/아크릴풍 아트 커버를 각각 생성했습니다. 기존 출판본 표지의 복제가 아닙니다.
   - 한 권당 펼친 재킷 이미지 한 장: 오른쪽 절반은 앞면, 왼쪽은 뒷면. CSS로 영역을 나누며 제목·저자·뒷면 소개는 실제 HTML 텍스트입니다.
   - `coverImage`, `coverBackImage`로 지정한 사용자 이미지가 우선합니다. 카탈로그에 없는 책은 기존 타이포 표지를 사용합니다.
   - 기존 드래그 회전, 앞면/뒷면 버튼, 책갈피, 페이지 넘김은 그대로 동작합니다.
   - WebP 16장 합계 약 1.6MiB, lazy loading. 생성 프롬프트는 `docs/cover-art.md` 참고.
   - 이미지 주소의 GitHub Pages 하위 경로는 `next.config.ts`의 `NEXT_PUBLIC_BASE_PATH`로 처리합니다.

3. **공용 작품 카탈로그** — `data/catalog.json`, `lib/catalog.ts`, `components/catalog/CatalogDetails.tsx`
   - 16권의 작품 소개, 한 줄 소개, 주제, 읽기 질문, 아트 커버 경로, 참고 URL/확인일을 저장했습니다.
   - 확인 가능한 7권은 출판사가 선정해 수록한 서평의 요약도 추가했습니다. 독자 리뷰, 전체 평점, 독립적인 여론 통계로 표시하면 안 됩니다. 참고 자료는 각 상세 화면에서 열 수 있습니다.
   - 요약은 출판사·저자/공공기관 자료 등을 참고해 새로 작성했습니다. 원문 본문이나 리뷰 전문을 수집·재배포하지 않았습니다. 읽기 질문은 리더가 제안한 질문입니다.
   - 카탈로그는 **작품(work) 단위**입니다. ISBN/번역/출판사/판형별 판본 DB가 아닙니다. 출처가 영어판이라고 한국어판의 쪽수·ISBN을 추정해 저장하지 마세요.
   - 정규화한 제목 **그리고 저자**가 모두 맞을 때만 자동 연결합니다. 검색은 유연하게, 저장 시 매칭은 정확하게 합니다. 제목만 비슷하다고 다른 작품에 붙이면 안 됩니다.
   - 현 단계는 정적 JSON 카탈로그입니다. 공유 서버 DB나 자동 크롤링 서버를 구축한 것은 아닙니다. 런타임 AI/API 호출은 없습니다.

4. **등록 및 개인 기록** — `lib/user-library.ts`, `data/books.ts`, `components/workspace/UserWorkspace.tsx`
   - `Book.catalogId`를 선택 필드로 추가했습니다. 기존 `reader.user-library.v1:<userId>` 저장 키와 `{version:1,books:[...]}` 구조는 유지합니다.
   - 새 책 추가 창에서 카탈로그 검색 결과를 선택하면 제목·저자·분류를 채웁니다. 쪽수는 사용자의 판본에 맞게 직접 입력합니다.
   - 등록 시 작품을 찾으면 소개를 연결하고 표지도 재사용합니다. 기존 개인 책도 제목/저자가 일치하면 상세 소개와 아트 커버가 표시됩니다.
   - 개인 ID, 메모, 독서 쪽수, 보유 표지를 유지합니다. 메모만 고친 경우 마지막 독서일을 갱신하지 않습니다. 모르는 작품에 임의의 소개를 만들지 않습니다.
   - `/library?add=<catalogId>`는 카탈로그에서 등록, `?new=1`은 직접 등록입니다. 개인 독서 모드는 `/book?id=<personalId>&read=1`입니다. 종이책/보유 책을 펼치고 타이머를 보는 기능이며 전자책 전문을 제공하는 뷰어가 아닙니다.
   - EPUB/PDF 업로드 파서는 이번에 만들지 않았습니다. 이후 업로드 기능을 만들면 추출한 제목/저자를 `matchCatalogBook`에 연결하세요. ISBN 매칭을 추가할 때는 검증된 판본 테이블을 별도로 만드세요.

5. **탐색** — `components/catalog/DiscoverCatalog.tsx`, `CatalogPage.tsx`, `app/discover/page.tsx`, `app/catalog/page.tsx`
   - 비로그인/사용자/제작자 모두 같은 작품 카탈로그를 둘러봅니다. 개인 추가는 기존 로그인 gate를 통과합니다.
   - 제목/저자/주제 검색, 장르·주제 필터, 제목/저자 정렬, 초기화, 8권씩 페이지 이동, 결과 없음 안내를 구현했습니다.
   - 이미 가진 작품은 내 서재의 해당 책으로 연결합니다. 작품 상세는 `/catalog?id=<catalogId>`로 구분합니다. 작품 카탈로그에 예시 사용자의 독서 기록을 섞지 마세요.
   - 예시 책 읽기 경로는 16권 모두 정적 생성하여 버튼이 404로 가지 않게 했습니다.

## 후속 변경 (Claude)

- **뒷면에서 돌리기**: 뒷면 상태에서는 종이가 책등 왼쪽으로 넘어가 있어 회전 중심이 어긋나 책이 화면 밖으로 나갔습니다. `BookViewer`의 `transformOrigin`을 보이는 책의 중심(`50 - shift %`)으로 옮겨, 뒷면에서 돌리면 제자리에서 앞면이 나옵니다.
- **책 설정 서랍**: 책 왼쪽에 **가로로** 꽂힌 설정 책갈피(`BookmarkTab`)를 누르거나 잡아당기면 왼쪽에서 **나무 서랍**이 나옵니다. 책갈피는 화면에 고정되지 않고 책 옆에 붙어 있어요(스크롤하면 함께 움직임). 책을 펼친(책갈피) 상태에서는 잠시 숨어요. `components/ui/PullDrawer.tsx`(`useDrawer` 훅 + 서랍), `components/book/BookSettings.tsx`(설정 항목; `<Section>`을 추가해 기능을 늘림). 공용 작품 화면(`/catalog`)에서는 끕니다(`BookStage settings={false}`).
- **원목 분위기**: 철제/단색 책장을 원목으로 바꿨습니다. 나뭇결은 `app/wood.css`(SVG 노이즈, 색 없음), 나무 색은 테마별 `--case-*`(`app/themes.css`). 책장(옆판·뒤판 널빤지·몰딩 윗판·받침·황동 이름판/조명), 서랍, 책 밑 책상(`.desk`), 탐색 진열대, 모바일 탭 바 모서리가 같은 결을 씁니다. 기본 테마 "서점의 밤"은 따뜻한 월넛, "종이"는 로고의 크림 + 오크.
- **서가 채우기**: 책이 적어도 휑하지 않게 내 책은 위 선반부터 빽빽하게 꽂고(예전: 선반마다 고르게 나눔), 남는 자리는 `fillersFor()`가 만드는 흐릿한 진열용 책·북엔드·눕힌 책·화분으로 채웁니다. `.bs-fill` 은 남은 폭만큼만 차지하고 한 줄에 안 들어가는 것은 통째로 숨겨 반쯤 잘린 책이 없습니다. 장식은 누를 수 없고 화면 읽기에서도 제외됩니다. 선택 동작(누르면 꺼내기/다시 누르면 꽂기, 오른쪽 정보 카드)은 그대로이며, 카드 색만 회색 → 크림 종이로 바꿨습니다.
- **독서 편의 (전자책 불편 조사 반영)**: 종이책을 선호하는 이유로 "책 속 위치감(두께·쪽)"이 자주 꼽히고, 전자책은 쪽 대신 %만 보이거나 메모를 내보낼 때 쪽 정보가 빠진다는 불만이 많아서 — `QuickLog`(상세·홈·읽기 모드에서 −/+·+10/+20/+30/끝까지로 쪽 기록, 남은 쪽 표시, 끝까지면 다 읽음 처리), 퍼센트 대신 남은 쪽 우선 표시, "기록 복사"(제목·저자·쪽·날짜·메모)를 넣었습니다.
